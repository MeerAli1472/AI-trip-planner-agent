# 🌍 AI Travel Planner – Agentic Application

An **AI-powered Travel Planner** built using **Large Language Models (LLMs), AI tools, and prompt engineering**.  
This application helps users easily **plan trips, explore tourist attractions, estimate travel costs, and get important travel information** in one place.

The system works as an **Agentic AI application**, where the AI model can use different tools to gather information and generate a **structured and intelligent travel plan**.

---

# 📌 Problem Statement

Planning a trip can be **time-consuming and complicated**. Travelers often need to search multiple websites to find useful information such as:

- Tourist attractions  
- Weather information  
- Currency exchange rates  
- Budget estimation  
- Trip itinerary planning  

This project introduces an **AI Agent Trip Planner for adventure travelers** that simplifies the process of planning trips.

#The AI agent helps users to:

- Discover **popular and hidden tourist attractions**
- Get **weather information for travel dates**
- Check **currency exchange information**
- Receive **recommendations for the best places to visit**
- **Manage and structure travel budgets**
- Estimate the **total cost of the trip**

The system also provides **visual resources such as attraction images**, helping users to **see a clear overview of the trip before planning everything at once**.

This makes travel planning **simpler, faster, and more organized**.

---

# 🎯 Objectives

The concept of a **Trip Planner** is simple, but the main objective of this project is to **explore how Large Language Models (LLMs) can be used in real-world business applications**.

This project focuses on the following objectives:

### 1️⃣ Exploring LLM Integration
Understanding how we can **bridge LLMs with real-time business products and services**.

### 2️⃣ Using LLMs with Tools
Learning how LLMs can be enhanced using **external tools such as APIs and data sources** to provide better and more useful responses.

### 3️⃣ Prompt Engineering
Using **prompt engineering techniques** to guide the LLM to generate structured and meaningful travel plans.

### 4️⃣ Building an Agentic AI System
Creating an **AI agent that can reason, gather information from tools, and generate a complete trip plan** for users.

# 🔑 APIs Used in the Project

Below are the external APIs used in this project and their purpose.

- **OPENAI_API_KEY**  
  Used to access OpenAI Large Language Models for generating intelligent responses and travel plans.

- **GROQ_API_KEY**  
  Used to run high-speed LLM inference using Groq-supported models for fast AI responses.

- **GOOGLE_API_KEY**  
  Used to access Google services such as maps, location data, and related travel information.

- **GPLACES_API_KEY**  
  Used to fetch place details, tourist attractions, and location information from Google Places API.

- **FOURSQUARE_API_KEY**  
  Used to discover nearby venues, restaurants, landmarks, and popular places.

- **TAVILY_API_KEY**  
  Used for real-time web search to retrieve updated information from the internet.

- **OPENWEATHERMAP_API_KEY**  
  Used to get weather forecasts and climate information for travel destinations.

- **EXCHANGE_RATE_API_KEY**  
  Used to retrieve currency exchange rates for estimating travel budgets.


# How to Run the Project
Step 1️⃣: Clone the Repository
--git clone https://github.com/yourusername/ai-travel-planner.git
cd ai-travel-planner
Step 2️⃣: Install Dependencies
--pip install -r requirements.txt 
Step 3️⃣: Configure Environment Variables in .env file
OPENAI_API_KEY=your_openai_api_key = ""
GPLACES_API_KEY=your_geoapify_api_key = ""
UNSPLASH_API_KEY=your_unsplash_api_key = ""
WEATHER_API_KEY=your_weather_api_key = ""
CURRENCY_API_KEY=your_currency_api_key = ""

Step 4️⃣: Run FastAPI Backend

--uvicorn main:app --reload --port 8000

Step 5️⃣: Run Streamlit Frontend
-- streamlit run app.py
